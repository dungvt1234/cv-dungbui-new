# Bùi Tuấn Dũng — Digital Profile

Website giới thiệu cá nhân với hiệu ứng soi lớp robot theo con trỏ. Trên thiết bị cảm ứng, chọn **Hiện người máy** để chuyển trạng thái.

## Chạy tại máy

Đây là trang tĩnh HTML, CSS và JavaScript, không cần cài thư viện. Từ thư mục dự án, chạy:

```bash
python3 -m http.server 8000
```

Sau đó mở http://localhost:8000. Có thể triển khai trực tiếp thư mục gốc lên dịch vụ hosting tĩnh. Hai ảnh WebP là các lớp chân dung được tạo từ ảnh tham chiếu của chủ website.
